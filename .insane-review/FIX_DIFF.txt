    fix(score): keep hard deterministic evidence floor on short (skipped) text
    
    reconcileScoreOverall discarded ALL deterministic evidence whenever
    deterministicScore.skipped was set — which analyzeText sets for any
    <=2-paragraph / <=2-sentence input. That silently dropped the near-proof
    markup-leakage floor (#332) and the structural-classifier floor on short
    text, so a short AI-leaked snippet scored 0 whenever the LLM returned 0.
    analyzeText documents skip as "advisory only" (it still computes the raw
    signals), so the scorer reading skipped as "distrust all deterministic
    evidence" was a code-contract mismatch.
    
    - scoreDeterministicSignals exposes evidenceFloor: the hard document-level
      floors (leakage + structural) separated from the coarse per-paragraph
      hot ratio (1/1 = 100 on one paragraph, unreliable on short text).
      overall is unchanged: max(hotRatio, evidenceFloor).
    - reconcileScoreOverall enforces evidenceFloor inside the skipped branch
      only (reason: deterministic-evidence-floor). Clean short prose has no
      hard floor and still defers to the LLM; non-skipped text keeps the
      existing divergence path untouched.
    
    Regression tests: exposed evidenceFloor, reconcile skipped/non-skipped
    paths, and a scoreText integration where a short leaked snippet + LLM=0
    floors to LEAKAGE_SCORE_FLOOR while a clean short reply stays 0.
    
    Reviewed via insane-review (GPT-5.6 Pro). Full unit+e2e (1555) + lint +
    benchmark (100%) green.
