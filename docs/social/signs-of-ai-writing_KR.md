# AI가 쓴 글처럼 보이는 신호 10가지

초안의 표현을 살필 때 쓰는 체크리스트입니다. 표에는 각 성공 사례 파일의 입력과 기대 출력을 발췌했습니다.

예시는 모델 기반 편집 검토로 정리했습니다. 실측 결과나 사람 평가가 아닙니다.

`failure` 파일은 별도의 입력과 기대 출력을 가진 대조군입니다. `success` 파일과 한 쌍으로 읽지 마세요. 출처나 수치가 없으면 저자에게 확인할 문제로 남깁니다.

| # | 신호 | 입력 → 기대 출력 발췌 | 독립 사례 |
|---:|---|---|---|
| 1 | 거대한 전환 표현이 겹칩니다. | "모바일 결제 시장에서 패러다임의 전환을 이끌어냈으며" → "모바일 결제 시장과 사용자 경험을 크게 바꿨다" | [성공 사례](../../examples/01-success-01.md) · [교정 없음 대조군](../../examples/01-failure-01.md) |
| 3 | `~하고`, `~하며`로 여러 주장을 잇습니다. | "청소년들의 창의성을 촉진하고, 지역사회 참여를 도모하며" → "청소년의 창의성을 키우고 지역사회 참여를 돕는다" | [성공 사례](../../examples/03-success-01.md) · [교정 없음 대조군](../../examples/03-failure-01.md) |
| 7 | 추상적인 수식어와 연결 표현이 몰립니다. | "다양한 혁신적인 접근 방식을 통해" → "여러 새로운 접근으로" | [성공 사례](../../examples/07-success-01.md) · [교정 없음 대조군](../../examples/07-failure-01.md) |
| 8 | `~적` 접미사가 거듭 나옵니다. | "혁신적이고 전략적인 접근을 통해" → "새롭고 전략을 갖춘 접근 덕분에" | [성공 사례](../../examples/08-success-01.md) · [교정 없음 대조군](../../examples/08-failure-01.md) |
| 9 | 부정 병렬로 주장을 키웁니다. | "산업 전반의 패러다임을 바꾸는 시도이다" → "산업 전반의 틀을 바꾸려는 시도다" | [성공 사례](../../examples/09-success-01.md) · [교정 없음 대조군](../../examples/09-failure-01.md) |
| 10 | 여러 문장에서 세 항목을 나열합니다. 항목 자체는 보존합니다. | "경제 성장, 사회 통합, 그리고 환경 보전" → "경제 성장과 사회 통합, 환경 보전" | [성공 사례](../../examples/10-success-01.md) · [교정 없음 대조군](../../examples/10-failure-01.md) |
| 13 | 문장마다 연결 표현이 반복됩니다. | "이러한 맥락에서 향후 추가적인 논의가 필요하다" → "추가 논의가 필요하다" | [성공 사례](../../examples/13-success-01.md) · [교정 없음 대조군](../../examples/13-failure-01.md) |
| 15 | 불릿마다 볼드 레이블을 붙입니다. | "**보안:** 종단간 암호화를 적용하여 데이터 유출 위험을 최소화했습니다" → "종단간 암호화를 적용해 데이터 유출 위험을 최소화했다" | [성공 사례](../../examples/15-success-01.md) · [교정 없음 대조군](../../examples/15-failure-01.md) |
| 22 | 의미 없이 길어진 도입이 들어갑니다. | "주목할 만한 점은 현 시점에서 볼 때 경쟁사 대비 기술력이 우위에 있다는 것이다" → "지금 경쟁사보다 기술력이 앞선다" | [성공 사례](../../examples/22-success-01.md) · [교정 없음 대조군](../../examples/22-failure-01.md) |
