# Pattern 36: 伪洞察铺垫 — Success

## Input Text

> 没人告诉你的招聘真相：内推比招聘网站好用。大多数人都搞错了，还在为职位帖子付钱。没人敢说的事实是——你最好的候选人早就认识你团队里的某个人。

## Expected Output

> 内推比招聘网站好用。大多数人对此判断有误，还在为职位帖子付钱。你最好的候选人早就认识你团队里的某个人。

## Applied Pattern

- Pattern 36 (伪洞察铺垫): 三处唯一内部人框架——"没人告诉你"、"大多数人都搞错了"、"没人敢说的事实"——给招聘行业反复在讲的观点借权威，却不提供证据。

## Judgment

**编辑判断（模型审阅）** — 独立保留内推比较、多数人仍付职位广告费的负面判断及候选人与团队的关系；删除12人录用、9人内推、3人一年内离职等捏造经历。
