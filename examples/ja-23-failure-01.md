# Pattern 23 (ja): 過剰なヘッジング — 失敗事例（誤検出）

## 入力テキスト

> この治療は中等症から重症の患者で症状を軽減する可能性がある。ただし、120例の第II相試験なので、効果量の確認にはより大きな試験が必要だ。

## 期待される出力

> （修正なし — Pattern 23 はこのテキストで発火すべきではない）

## 適用パターン

- Pattern 23 (過剰なヘッジング): 「可能性がある」が単一のヘッジである。「必要だ」は追加試験の必要性を述べる。

## 判定

**無修正の対照例** — 初期の試験に見合う単一の「可能性がある」と追加試験の必要性を残し、効果を断定しない。
